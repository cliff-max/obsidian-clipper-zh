# v1.6.0 发布说明

**主题：无字幕视频 AI 转写（B 站 + 抖音）与抖音剪藏支持**

## 新增

### AI 语音转写：没有字幕的视频也能剪藏字幕

- B 站无 CC/AI 字幕轨的视频（如硬字幕教学合集）与抖音无字幕视频，点击视频页右下角「AI 转写字幕」即可生成带时间轴的完整字幕，重新剪藏即得与原生字幕一致的笔记（按章节归组、`mm:ss` 时间戳）
- 音频在本地页面内解码并按语音静音智能切分，仅上传匿名音频块到语音识别服务；结果按视频缓存，重复剪藏零成本
- 支持断点续传：浏览器休眠、页面关闭、网络中断均可恢复，已完成部分不重复计费
- 长任务稳定性：签名地址过期自动刷新、CDN 多节点轮换、限流长退避、失败段自动补救（重试/换模型/拆分），仍失败的段在笔记中标注时间区间与原因，可一键补齐
- 识别热词优化：自动注入视频标题/UP 主/简介作为上下文，降低专有名词误识别

### 抖音视频剪藏

- 详情页、推荐流/关注流当前观看的视频、UP 主主页页内播放均支持提取简介与字幕（抖音原生 AI 字幕轨，时间轴精确）
- 无字幕视频可触发 AI 转写（时长上限约 20 分钟）
- 陈列页（用户主页/收藏/搜索）给出指引，不再抓取整页无效内容

### 体验改进（本版本同期）

- 无字幕视频自动探测：打开视频页即出现转写入口，无需先剪藏一次
- 转写启动即时反馈（「转写启动中…」），修复长视频启动期间点击无响应的问题
- 嵌入式剪藏保存后侧栏自动收起，通知文案精简

## 使用要求

- **AI 转写需自备 [SiliconFlow](https://siliconflow.cn) API Key**（扩展设置 → AI 转写）；默认模型 `Qwen/Qwen3-ASR-1.7B` 约 ¥0.81/小时音频，可切换为免费的 `FunAudioLLM/SenseVoiceSmall` 或任意 OpenAI 兼容端点
- B 站 AI 字幕与转写均需浏览器已登录 B 站

## 已知限制

- 抖音转写时长上限约 20 分钟（更长视频会明确提示）
- 充电专属等付费内容的音频受平台权限保护，无法转写（会给出明确提示）
- 语音识别文本可能存在专有名词误差（已通过热词缓解）

## 安装

- Chrome / Edge：下载 `obsidian-clipper-zh-1.6.0-chrome.zip`，解压后 `chrome://extensions` → 开发者模式 → 加载已解压的扩展程序
- Firefox：`obsidian-clipper-zh-1.6.0-firefox.zip`，`about:debugging` 临时载入
- 从 1.5.x 升级：直接覆盖加载新目录，已有设置与转写缓存保留（旧版转写缓存自动兼容）
